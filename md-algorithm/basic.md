## 前端常见的数据结构? 它们对应的有什么基础算法和应用场景？

### 1. 数组 Array

数组是数据的元素集合，字符串是字符的有序序列。

**`基础算法`**：遍历、增删改查、冒泡/插入/快速排序、二分查找、双指针、滑动窗口、数组扁平化、去重、交集/并集

**`应用场景`**
- 列表渲染（React/Vue 的 `v-for` / `map`）
- 数据缓存（如表格数据、分页数据、下拉选项）
- 栈/队列底层实现（配合 `push/pop` 或 `shift/unshift`）
- 批量处理数据、矩阵网格布局

### 2. 栈 Stack（后进先出 LIFO）

栈（Stack）是一种运算受限的`线性数据结构`，遵循`后进先出（LIFO）原则`，仅允许在栈顶进行插入（入栈）和删除（出栈）操作。

**`基础算法`**：入栈 push、出栈 pop、取栈顶 peek、括号匹配、表达式求值、递归模拟、逆序遍历

**`应用场景`**
- 浏览器路由前进后退
- 路由历史（`history.back()` 或 React Router 的 goBack）
- 撤销/恢复（编辑器、绘图工具）
- 函数调用栈（递归、异步调用栈）
- 括号/标签匹配（编译原理中的词法解析）
- 深度优先遍历（DFS）
- 弹窗层层关闭

### 3. 队列 Queue（先进先出 FIFO）

队列是一种`先进先出（FIFO, First-In-First-Out）的线性数据结构`，类似于现实生活中的排队场景。

**`基础算法`**：入队 enqueue、出队 dequeue、普通队列、循环队列、优先队列

**`应用场景`**
- 事件循环的任务队列（宏任务/微任务异步队列）
- HTTP 请求并发控制（限制同时请求数）
- 消息通知队列（弹窗按顺序展示）
- 广度优先遍历（BFS，如 DOM 树遍历）
- 键盘/鼠标事件的节流处理
- 图片预加载队列

### 4. 链表 单向/双向链表

链表（Linked List）是一种物理存储单元上`非连续、非顺序`的存储结构，是一种`线性数据结构`,数据元素的逻辑顺序是通过链表中的`指针链接次序`实现的。

**`基础算法`**：链表反转、链表遍历、快慢指针判环、检测环、链表合并、删除节点

**`应用场景`**
- React Fiber 架构（链表树，可中断的递归）
- 可复用输入历史（LRU 缓存的前端实现）
- 拖拽排序的底层模型（双链表）
- 图片预加载队列管理
- 长列表虚拟滚动、轮播图节点串联
- 不连续数据高效增删

### 5. 哈希结构 Object / Map / Set

哈希表是一种通过键（Key）直接访问值（Value）的数据结构，可以实现 O(1) 时间复杂度的插入、删除和查找。

`JavaScript 中的哈希表`：

| 实现方式 | 特点 | 适用场景 |
|---------|------|---------|
| **普通对象 `{}`** | 键只能是字符串/Symbol | 简单配置、字典 |
| **`Map`** | 键可以是任意类型，有序，大小易得 | 复杂键、频繁增删 |
| **`Set`** | 只存键不存值，自动去重 | 判断存在性、去重 |
| **`WeakMap`/`WeakSet`** | 键是对象且弱引用 | 防止内存泄漏（DOM关联数据）|

```javascript
// 对象形式
const obj = { name: '张三', age: 25 };

// Map 形式（更推荐用于哈希表场景）
const map = new Map();
map.set('name', '张三');
map.set({ id: 1 }, '用户数据');  // 对象作为键
console.log(map.get('name'));     // '张三'
```

::: tip 哈希冲突及解决
**问题**：不同键可能算出同一个数组下标（比如 "ab" 和 "ba" 哈希值相同）

**解决方案**：

1. **链地址法**：每个桶存一个链表，冲突的元素挂在后面（最常用）
2. **开放地址法**：冲突后找下一个空位放进去

JavaScript 引擎（V8）内部会对 Map/Object 自动处理冲突，开发者无需关心。
:::

**`基础算法`**：哈希查找、数组去重、求交集/差集/并集、键值映射、哈希冲突处理（链地址/开放定址）、计数法

**`应用场景`**
- Object：配置项、状态对象、简单字典
- Map：任意类型key、路由权限映射、缓存存储
- Set：数据去重、权限白名单、标签去重
- 存储组件状态（Redux/Vuex 的 state 本质上是大哈希表）
- 键值对配置管理（`localStorage` 的二次封装）

### 6. 树 二叉树/多叉树/DOM树

树是一种`非线性的层次化数据结构`，由节点（Node）和边（Edge）组成

**`基础算法`**：前序/中序/后序遍历（递归+非递归）、层序遍历（BFS）、DFS 深度优先、BFS 广度优先、递归遍历

**`应用场景`**
- DOM 树操作（查找、遍历、更新）
- 虚拟 DOM diff 算法（树递归比较）
- 组件树渲染（React/Vue 的父子组件嵌套）
- 文件目录结构展示（侧边栏文件夹）
- 菜单权限管理（树形权限点）
- AST（抽象语法树，Babel/ESLint 解析代码）
> 实际前端更常用 **平衡树**（如红黑树）的变体思想，但一般由封装库实现（如 `Map` / `Set` 底层）。

### 7. 堆 Heap（大顶堆/小顶堆）

堆是一种`‌完全二叉树`（所有层都填满，除了最后一层，最后一层从左到右填充）‌结构的顺序存储数组

**`基础算法`**：插入（上浮）、删除堆顶（下沉）、堆排序、优先队列、TopK 问题

**`应用场景`**
- 任务调度（高优先级任务先出列）
- TopK 问题（如页面展示最热门的 10 篇文章）
- 合并 K 个有序链表（虚拟滚动数据分片）
- 中位数实时获取（用两个堆）
- 消息优先级
- 定时任务优先级排序

### 8. 图 Graph

图是一种`非线性数据`结构，由节点（Vertex）和边（Edge）组成，用于表示实体之间的关系。

**`基础算法`**：
图的遍历、DFS/BFS、最短路径（Dijkstra）、拓扑排序、检测环

**`应用场景`**
- 拓扑依赖分析（Webpack 模块依赖图）
- 流程图（节点+连线，如流程编辑器、低代码平台）
- 路由权限依赖分析（页面跳转关系分析）
- 可视化关系图谱（用户关注图谱展示）
- 权限关系判断（有向图的可达性）

### 9. 矩阵（二维数组）
**`基础算法`**：矩阵遍历、旋转、回溯

**`应用场景`**：九宫格、棋盘游戏、地图格子、大屏网格布局、像素矩阵处理


## 时间 & 空间复杂度

`衡量算法效率的两个核心指标`，用**大 O 表示法**（Big O Notation）描述 **`最坏情况`** 下的性能。

::: tip 大O表示法规则
1. 只保留**最高次项**
2. 忽略常数、忽略低次项
3. 只看**最坏情况**
:::

### 时间复杂度 `O(n)`

衡量 **`算法执行耗时`** 随数据规模（n）增长的变化趋势，**不看具体秒数，只看量级**。`消耗CPU`

`常见时间复杂度（从快到慢）`：**O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)**

| 复杂度 | 名称 | 典型算法 | n=1000 时的操作次数 |
|--------|------|----------|---------------------|
| **O(1)** | 常数阶 | 数组随机访问、哈希表查找 | 1 |
| **O(log n)** | 对数阶 | 二分查找、平衡树操作 | 10 |
| **O(n)** | 线性阶 | 遍历数组、简单查找 | 1000 |
| **O(n log n)** | 线性对数阶 | 快速排序、归并排序 | 10000 |
| **O(n²)** | 平方阶 | 冒泡排序、双重循环 | 1,000,000 |
| **O(2ⁿ)** | 指数阶 | 递归斐波那契（无优化） | 天文数字 |
| **O(n!)** | 阶乘阶 | 旅行商问题暴力解 | 不可行 |

::: tip 计算规则
1. **忽略常数**：O(2n) → O(n)，O(100) → O(1)
2. **保留最高次项**：O(n² + n) → O(n²)
3. **嵌套循环乘**：双重 for 循环 → O(n × m)
4. **顺序结构加**：O(n) + O(n²) → O(n²)
:::

::: tip 口诀记忆
- **常数对数组，对数找二分**（O(1) 数组访问，O(log n) 二分查找）
- **线性单循环，平方双嵌套**（O(n) 一个 for，O(n²) 两个 for）
- **指数是递归，空间可换时**（优化递归用 DP，缓存用空间换时间）
:::

::: details 代码示例
```javascript
// O(1) - 常数阶
function getFirst(arr) {
    return arr[0];  // 无论数组多大，只做一次操作
}

// O(n) - 线性阶
function findMax(arr) {
    let max = arr[0];
    for (let i = 1; i < arr.length; i++) {  // 循环 n 次
        if (arr[i] > max) max = arr[i];
    }
    return max;
}

// O(n²) - 平方阶（冒泡排序）
function bubbleSort(arr) {
    for (let i = 0; i < arr.length; i++) {      // n 次
        for (let j = 0; j < arr.length - 1; j++) {  // n 次
            if (arr[j] > arr[j+1]) {
                [arr[j], arr[j+1]] = [arr[j+1], arr[j]];
            }
        }
    }
    return arr;
}

// O(log n) - 对数阶（二分查找）
function binarySearch(arr, target) {
    let left = 0, right = arr.length - 1;
    while (left <= right) {
        let mid = Math.floor((left + right) / 2);
        if (arr[mid] === target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
    // 每次循环规模减半，2^k = n → k = log₂n
}

// O(n log n) - 快速排序（平均情况）
function quickSort(arr) {
    if (arr.length <= 1) return arr;
    const pivot = arr[0];
    const left = [], right = [];
    for (let i = 1; i < arr.length; i++) {  // O(n) 分区
        arr[i] < pivot ? left.push(arr[i]) : right.push(arr[i]);
    }
    return [...quickSort(left), pivot, ...quickSort(right)];  // 递归 log n 层
}
```
:::


### 空间复杂度 `O(n)`

衡量 **`算法额外占用内存空间`** 随数据规模（n）增长的变化趋势，看额外开了多少数组、变量、递归栈。`消耗内存`

`常见空间复杂度`

| 复杂度 | 说明 | 示例 |
|--------|------|------|
| **O(1)** | 常数空间，不随 n 变化 | 临时变量、原地排序 |
| **O(n)** | 线性空间，需要 n 个额外空间 | 拷贝数组、递归栈深度 n、哈希表存储  |
| **O(n²)** | 平方空间 | 二维矩阵存储 |

::: tip 计算规则
1. 只计算额外空间（不包括输入数据本身）
2. 递归调用栈计入空间复杂度
:::

::: details 代码示例
```javascript
// O(1) - 常数空间
function sum(arr) {
    let total = 0;           // 只用一个变量
    for (let i = 0; i < arr.length; i++) {
        total += arr[i];
    }
    return total;
}

// O(n) - 线性空间
function copyArray(arr) {
    const newArr = new Array(arr.length);  // 额外申请 n 个空间
    for (let i = 0; i < arr.length; i++) {
        newArr[i] = arr[i];
    }
    return newArr;
}

// O(n) - 递归栈空间（阶乘）
function factorial(n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);  // 递归深度 n，栈占用 O(n)
}

// O(n²) - 平方空间
function createMatrix(n) {
    const matrix = [];
    for (let i = 0; i < n; i++) {
        matrix[i] = new Array(n);  // n × n 的空间
    }
    return matrix;
}
```
:::


### 时间 & 空间权衡

- 时间优先：实时系统、高频交易（如用空间换时间的缓存策略）。
- 空间优先：嵌入式设备、内存受限场景（如用时间换空间的流式处理）。

**鱼与熊掌不可兼得**：很多时候用空间换时间（缓存、预计算）。

```javascript
// 例子：斐波那契数列

// 方案1：递归（时间差，空间好）
// 时间复杂度 O(2ⁿ)，空间复杂度 O(n)（递归栈）
function fib1(n) {
    if (n <= 1) return n;
    return fib1(n-1) + fib1(n-2);
}

// 方案2：动态规划（时间好，空间差）
// 时间复杂度 O(n)，空间复杂度 O(n)
function fib2(n) {
    const dp = [0, 1];
    for (let i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}

// 方案3：滚动数组（折中）
// 时间复杂度 O(n)，空间复杂度 O(1)
function fib3(n) {
    if (n <= 1) return n;
    let prev = 0, curr = 1;
    for (let i = 2; i <= n; i++) {
        [prev, curr] = [curr, prev + curr];
    }
    return curr;
}
```
