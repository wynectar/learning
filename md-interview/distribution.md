## 2026 年前端面试

### 内容分布

| 考察模块 | 预估占比 | 核心考察点（高频 & 重点） | 考察形式与能力要求 |
| :--- | :--- | :--- | :--- |
| **项目经历与工程化** | **约30%** | - **复杂场景实现**：虚拟列表（尤其是动态高度）、复杂表单状态管理、微前端架构设计与通信。<br>- **性能优化**：首屏与构建优化（如靠前的Chunk、Tree Shaking）、运行时性能（内存泄漏、长任务）。<br>- **工程化基建**：自定义脚手架、CICD流水线配置、Monorepo管理、Babel插件。 | 深挖细节，重点考察技术决策过程和量化成果（例如“首屏加载时间减少了X%”）。 |
| **前端基础与原理** | **约25%** | - **JavaScript**：`this`、原型链、异步（Event Loop、Promise）、垃圾回收。<br>- **CSS**：布局（Flex/Grid）、响应式、层叠上下文、新特性（容器查询）。<br>- **浏览器与网络**：渲染原理（重排/重绘）、HTTP缓存与协议、跨域解决方案。<br>- **框架（以React为主）**：Fiber架构与时间切片、Hooks原理（如`useEffect`的依赖收集）、合成事件。 | 死记硬背“八股文”回报降低，更侧重考察底层原理在实际问题中的应用与分析。 |
| **AI工程化能力** | **约20%** | - **AI辅助开发**：如何设计Prompt、如何保证AI生成代码的安全与质量。<br>- **AI应用集成**：处理大模型流式响应（解析不完全的JSON块）、设计Agent工作流（如RAG检索增强）。<br>- **AI工具链**：VSCode插件（GitHub Copilot、Cursor）、AI Code Review。 | 面试官想了解的是你**如何利用AI提效**，而非简单的API调用。重在展示工程化应用与最佳实践。 |
| **算法与手写代码** | **约15%** | - **手写核心功能**：`Promise.all`、带并发限制的调度器、深拷贝、数组拍平去重。<br>- **数据结构与算法**：常见数据结构的应用（数组、字符串）、DFS/BFS、简单的动态规划。 | 主要出现在在线笔试或第一轮面试，注重代码逻辑清晰、边界条件完整、时间/空间复杂度分析。 |
| **系统设计** | **约10%** | - **前端架构设计**：设计前端监控SDK、设计高可用的支付页面、设计实时协作编辑器。<br>- **全栈/接口设计**：设计BFF层、设计API接口、设计Webhook系统。 | 常见于中大型或外企面试，考察你的抽象能力、架构思维和数据流设计能力。 |

### 按面试流程的常见环节分布

除了按知识模块划分，你还可以按面试流程来准备，这样更有针对性：

| 面试环节 | 常见时长 | 考察重点 | 淘汰率 |
| :--- | :--- | :--- | :--- |
| **在线笔试 / 初筛** | 60-90分钟 | 算法与数据结构（LeetCode中等难度）、JavaScript基础、CSS布局、少量React原理。 | **较高**，主要用于快速筛选。 |
| **第一轮：技术面** | 45-60分钟 | 前端基础与原理（深度提问）、项目经历（开始引入场景题）、手写代码（核心功能）。 | 中等，基础不牢容易淘汰。 |
| **第二轮：深入技术/项目面** | 60-90分钟 | **项目经历（核心）**：深度追问技术选型、难点攻克、量化成果。<br>**工程化与性能**：CI/CD、打包优化、监控。<br>**AI工程化**：AI集成实践。 | **最高**，这是区分候选人的关键轮次。 |
| **第三轮：交叉/架构面** | 45-60分钟 | **系统设计**：考察架构抽象能力。<br>**软技能**：跨团队协作、技术规划、学习能力。 | 中等，看重潜力和沟通。 |
| **HR面** | 30分钟 | 价值观匹配、稳定性、职业规划、薪资沟通。 | 较低，主要看软素质。 |

### 给你的核心策略建议

1.  **项目经历是“定生死”的关键**：
    -   准备好1-2个最能体现你技术深度的项目，按照 **STAR原则**（背景、任务、行动、结果）组织语言。
    -   对每个技术决策都要能回答“为什么选A不选B？”。
    -   **复盘量化成果**：比如“优化后，LCP从2.5s降到1.2s”。

2.  **重视AI工程化，而不只是AI调用**：
    -   在简历和项目中，体现你如何将AI融入工作流。例如：“设计并实现了基于AI的代码审查助手，将重复问题检出率提升30%”。
    -   尝试了解`LangChain`、`Vercel AI SDK`等前沿工具，能说出它们在处理流式响应上的优势。

3.  **算法保持手感，但不求偏难怪**：
    -   重点攻克 **数组、字符串、哈希表、递归/DFS/BFS、简单的DP**。
    -   手写Promise周边和深拷贝等，要能**一次性写出健壮的代码**。
